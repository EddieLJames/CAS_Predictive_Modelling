# CAS\_Predictive\_Modelling

An end to end predictive modelling project for pricing a dormitory renter's insurance product for 10,000 students.


**Files**

*CAS\_EDA* - R file containing Exploratory data analysis 

*CAS\_Model\_Fitting\_and\_Factors* - Python file for model analysis, fitting, prediction of pure losses and generation of pricing factors fed into excel file

*CAS\_Pricing\_Model* - Excel file for final pricing and analysing assumptions.
